## Single-Player-Setup

Das Mindest-Setup für ein Single-Player-Three.js-Spiel benötigt eine `Game`-Instanz.

```typescript
import Game from '@mavonengine/core/Game'

const game = new Game([
  // Assets, die beim Start geladen werden, siehe Ressourcen
  { name: 'character', type: 'gltfModel', path: '/character.glb' },
])
```

`Game` ist ein Singleton. Verwende `Game.instance()`, um die Instanz abzurufen. Es:
- Erstellt automatisch ein `<canvas>` und fügt es dem Dokument hinzu
- Richtet den WebGL-Renderer, die Perspektivkamera und den Audio-Listener ein
- Startet die Render-Schleife über `requestAnimationFrame`
- Richtet den Input-Manager ein (Tastatur, Maus und Gamepads)

Übergib eine Rapier-Welt als zweites Argument, um Physik zu aktivieren, siehe [Physik](/de/kernkonzepte/physik).

### Eine Szene laden und die Framerate begrenzen

```typescript
// scenes/main.json laden (Lichter, Boden, Modelle…)
game.openScene('main')

// Höchstens 60 Frames pro Sekunde rendern. 0 = kein Limit
game.renderer.maxFps = 60
```

`maxFps` drosselt nur das Rendering: Spiel-Tick und Physik behalten ihre eigene Rate. Du kannst den Wert auch live im Debug-Panel ändern.

## Multiplayer-Setup

Für Multiplayer läuft auf dem Server `BaseGame` headless, und die Clients laufen mit `Game`. Am schnellsten geht es mit dem Multiplayer-Template:

```bash
npx @mavonengine/cli create my-game
```

Siehe den Abschnitt [Netzwerk](/de/netzwerk) für das vollständige Setup.

## Entwicklungsmodus

Hänge `#debug` an deine URL an, um das Debug-Panel (Tweakpane) und das Overlay der Physik-Collider zu aktivieren.

```
http://localhost:8050/#debug
```

Drücke `.`, um den [Level-Editor](/de/kernkonzepte/level-editor) zu öffnen.

## Nächste Schritte

- Lerne das [Entity-System](/de/kernkonzepte/entity-system) kennen, um Spielobjekte zu erstellen
- Füge [Physik](/de/kernkonzepte/physik) hinzu und baue deine Map mit [Szenen](/de/kernkonzepte/szenen)
- Richte [Ressourcen laden](/de/ressourcen) ein, um Modelle und Texturen zu laden
- Erkunde [Netzwerk](/de/netzwerk), um Multiplayer-Unterstützung hinzuzufügen
- Nutze die [CLI](/de/werkzeuge/cli), [Plugins](/de/werkzeuge/plugins) und [KI-Assistenten](/de/werkzeuge/ki-assistenten)

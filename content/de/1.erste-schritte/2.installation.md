Benötigt **Node 24** oder neuer.

## Einrichten

Verwende den `create`-Befehl der [MavonEngine-CLI](/de/werkzeuge/cli), um ein neues Projekt einzurichten.

### Multiplayer

```bash
npx @mavonengine/cli create my-game
```

Das lädt das Multiplayer-Template herunter, installiert seine Abhängigkeiten, startet den Spielserver und öffnet das Spiel in deinem Browser — mit einem Live-[Dashboard](/de/werkzeuge/monitoring) des Servers im Terminal.

Das Multiplayer-Template enthält das autoritative Server-Setup, Netzwerk-Boilerplate sowie eine fertige Client/Server-Aufteilung.

> `npx @mavonengine/create-bootstrap` funktioniert weiterhin und leitet an `mavonengine create` weiter.

## Projekt starten

```bash
cd my-game
npm run dev
```

`npm run dev` führt `mavonengine dev` aus: Es startet Spielserver und Client gemeinsam und zeigt das Dashboard an. Alles läuft auf einem Port — der Spielserver liefert den Client (im Dev-Modus mit Hot Reload) und den Spiel-Socket neben seiner eigenen API aus.

| URL | Beschreibung |
|-----|-------------|
| `http://localhost:8050/` | Das Spiel |
| `http://localhost:8050/#debug` | Debug-Modus: Debug-UI und Physik-Collider |
| `http://localhost:8050/api/game/health` | Health-Endpunkt des Servers |

Drücke `.` im Spiel, um den [Level-Editor](/de/kernkonzepte/level-editor) zu öffnen.

## Projektstruktur

| Pfad | Beschreibung |
|------|-------------|
| `client/` | Das Browserspiel (`Game`), gebaut mit Vite |
| `server/` | Der Spielserver (`Server`); `server/src/Base/` enthält die mit dem Client geteilten Klassen |
| `scenes/` | [Szenen](/de/kernkonzepte/szenen)-Dateien, die von beiden Seiten geladen werden |
| `mavonengine.json` | Aktivierte [Plugins](/de/werkzeuge/plugins) |
| `.mcp.json` | Registriert den [MCP-Server](/de/werkzeuge/ki-assistenten) für KI-Assistenten |

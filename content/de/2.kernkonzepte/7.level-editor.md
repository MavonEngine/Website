## Den Editor öffnen

Der Editor steckt in `@mavonengine/editor` und wird nur in der Entwicklung geladen. Registriere ihn mit `Game.devModeHook`, bevor du das Spiel erstellst:

```typescript
import Game from '@mavonengine/core/Game'

if (import.meta.env.DEV) {
  Game.devModeHook = () => {
    import('@mavonengine/editor').then(({ default: Editor }) => Editor.registerListener())
  }
}
```

Drücke dann `.` (oder `Insert`) im Spiel. Projekte, die mit `mavonengine create` erstellt wurden, sind bereits eingerichtet.

## Das laufende Spiel bleibt

Der Editor behält die geladene Szene und die Verbindung zum Spielserver bei, sodass die anderen Spieler und alles andere, was der Server sendet, während des Bearbeitens weiter angezeigt werden.

- Der Client teilt dem Server mit, dass er den Editor geöffnet hat. Der Server entfernt seinen Spieler, zählt ihn nicht mehr als Spieler und sendet ihm **alle** Entities der Welt, nicht nur die in der Nähe eines Spielers.
- Öffnet sich der Editor, bevor das Spiel einem Server beigetreten ist, verbindet sich das Multiplayer-Template als Zuschauer, ohne eigenen Spieler.

## Layout

| Bereich | Eingebaute Panels |
|------|-----------------|
| Links | **Scene** (die Objekte der aktiven Szene, Live-Entities und ungespeicherte Änderungen), **Explorer** |
| Unten | **Assets** (geladene Modelle und Texturen; zieh eines in die Szene) |
| Rechts | **Properties** des ausgewählten Objekts |

Die Statusleiste zeigt verbundene Gamecontroller; klick auf einen, um die Controller-Debug-Ansicht mit seinen Live-Buttons und -Sticks zu öffnen.

## Szenen speichern

`Ctrl+S` / `Cmd+S` speichert die aktive [Szene](/de/kernkonzepte/szenen) über den Dev-Server nach `scenes/<name>.json`. Der Spielserver beobachtet die Datei, lädt sie neu, und jeder Client bekommt die neue Map. Wenn du ein Plugin-Prefab platzierst, wird es außerdem zu den `prefabs` des Plugins in `mavonengine.json` hinzugefügt, damit seine Assets im Release mitgeliefert werden.

## Eigene Panels

Docke deine eigenen Tools neben den eingebauten Panels an. Übergib eine React-`component` oder eine `mount`-Funktion, um mit etwas anderem zu rendern:

```typescript
import Editor from '@mavonengine/editor'

Editor.registerPanel({
  id: 'my-tools',
  title: 'My tools',
  location: 'right', // 'left' | 'bottom' | 'right'
  mount(container, editor) {
    container.textContent = 'Hello from my panel'
    return () => { container.textContent = '' } // Aufräumen
  },
})
```

`registerPanel()` funktioniert vor oder nach dem Start des Editors und gibt eine Funktion zurück, die das Panel wieder entfernt. Nach dem Start machen `editor.addPanel()` und `editor.removePanel(id)` dasselbe. Plugins bekommen den Editor in ihrem `editor(ctx)`-Hook, siehe [Plugins](/de/werkzeuge/plugins).

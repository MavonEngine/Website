Ein Material-Graph ist ein Material aus Nodes. Er wird zu einem three.js-[TSL](https://github.com/mrdoob/three.js/wiki/Three.js-Shading-Language)-Node-Material (`MeshStandardNodeMaterial`) kompiliert und läuft damit auf dem WebGL-2- und dem WebGPU-Backend des [Renderers](/de/kernkonzepte/spielschleife#renderer). Du baust sie in der **Graphs**-Ansicht des [Level-Editors](/de/kernkonzepte/level-editor), die über den Nodes eine Live-Vorschau des Materials zeigt.

Material-Graphen teilen Dateiformat, Editor und [Subgraphen](/de/kernkonzepte/logik-graphen#subgraphen) mit den [Logik-Graphen](/de/kernkonzepte/logik-graphen): `graphs/<name>.graph.json` mit `"kind": "material"`.

## Einen verwenden

Wähle ihn im Properties-Panel als **material graph** eines [Primitives](/de/kernkonzepte/szenen#eingebaute-typen-client), oder setze sein Prop `materialGraph` in der Szenendatei. Ohne zeichnet das Primitive wieder mit seinem eigenen Material.

```typescript
primitive.setMaterialGraph('lava')
primitive.setMaterialGraph(undefined) // zurück zum eigenen Material
```

Auf jedem Mesh über die Bibliothek der Material-Graphen des Spiels. Alle Meshes mit demselben Graphen teilen ein kompiliertes Material, und eine Änderung am Graphen (der Editor macht das bei jeder Bearbeitung) legt das neue auf alle:

```typescript
import { materialGraphs } from '@mavonengine/core/Graph/Material/MaterialGraphs'

await materialGraphs.apply(mesh, 'lava')
materialGraphs.release(mesh) // dem Graphen nicht mehr folgen, das Material bleibt
```

## Nodes

| Kategorie | Nodes |
|-----------|-------|
| Ausgabe | **Material Output**: Base Color, Opacity, Roughness, Metalness, Emissive, Normal, Position Offset. Nicht verbundene Eingänge behalten die Standardwerte des Materials. Ein Graph hat genau einen |
| Oberfläche | **UV**, **World Position**, **Local Position**, **World Normal**, **View Direction** |
| Textur | **Texture**: tastet eine geladene Textur-[Ressource](/de/ressourcen) nach Name an einer UV ab. Eine nicht geladene erscheint magenta |
| Noise | **Perlin Noise** (3D), **Value Noise** (2D) |
| Eingabe | **Float**, **Vec2**, **Vec3**, **Vec4**, **Color**, **Parameter**, **Time** |
| Mathe, Vektor | Wie in Logik-Graphen: Add, Multiply, Mix, Clamp, Smoothstep, Remap, Sine, Fraction, … Combine, Split, Length, Dot, Normalize, Cross |

**Parameter**-Nodes lesen die Parameter des Graphen, die zu Uniforms des kompilierten Materials werden. **Comment**- und **Group**-Nodes kommentieren den Graphen, wie in Logik-Graphen.

## Eigene Nodes

Ein Material-Node braucht neben seiner Definition eine TSL-Implementierung. Registriere ihn mit `registerNode()` und `registerTslNode()`, oder aus einem Plugin mit `ctx.registerNode(definition, tsl)`, siehe [Plugins](/de/werkzeuge/plugins#graphen-und-nodes). Ein Node, der nur auf dem WebGPU-Backend funktioniert, setzt `requires: 'webgpu'`, und der Editor warnt unter WebGL 2 davor.

## Aus Code kompilieren

```typescript
import { compileMaterialGraph } from '@mavonengine/core/Graph/Material/compileMaterialGraph'

const { material, parameters } = compileMaterialGraph(graph, {
  parameters: { glow: 2 },
  textures: name => game.resources.items[name],
})
parameters.glow.value = 3 // ein Uniform: ändert sich ohne neu zu kompilieren
```

Ein Graph mit Problemen wirft einen `MaterialGraphError`, der sie auflistet.

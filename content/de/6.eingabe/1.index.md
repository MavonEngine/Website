`InputManager` verfolgt den Status von Tastatur, Maus und Gamepads und bietet Raycasting-Utilities zur Umrechnung von Bildschirmkoordinaten in Weltpositionen.

```typescript
// Zugriff über game.input
const input = game.input
```

## Tastatur

Tasten werden durch ihren [KeyboardEvent.code](https://developer.mozilla.org/en-US/docs/Web/API/KeyboardEvent/code)-Wert verfolgt.

```typescript
// Prüfen ob eine Taste aktuell gedrückt ist
if (input.keysPressed.has('KeyW')) {
  // W ist gedrückt
}

if (input.keysPressed.has('Space')) {
  // Leertaste ist gedrückt
}
```

### Tastatur-Events

```typescript
input.on('keydown', (event: KeyboardEvent) => {
  console.log('gedrückt:', event.code)
})

input.on('keyup', (event: KeyboardEvent) => {
  console.log('losgelassen:', event.code)
})
```

## Maus

Der Status der Maustasten wird nach Tastenindex verfolgt (0 = links, 1 = Rad, 2 = rechts).

```typescript
if (input.mousePressed.has(0)) {
  // Linke Maustaste ist gedrückt
}
```

### Cursorposition

Die normalisierte Cursorposition im Bereich `[-1, 1]` auf beiden Achsen:

```typescript
input.cursor // THREE.Vector2, bei jedem mousemove aktualisiert
```

## Weltposition-Raycasting

Wandle die Cursorposition mit `getPointerWorldPosition` in eine Weltkoordinate um:

```typescript
const worldPos = input.getPointerWorldPosition()
// Gibt THREE.Vector3 | null zurück
```

**Parameter:**

| Parameter | Typ | Beschreibung |
|-----------|------|-------------|
| `except` | `Object3D[]` | Objekte, die vom Raycasting ausgeschlossen werden |
| `only` | `Object3D[]` | Nur gegen diese Objekte raycasten |

```typescript
// Nur gegen das Terrain raycasten
const pos = input.getPointerWorldPosition(undefined, [terrain.instance])
```

## Gamepads

Xbox-, PlayStation-, Nintendo- und generische Controller stehen über `input.gamepads` zur Verfügung, einen `GamepadManager`. Er wird einmal pro Spiel-Update abgefragt, bevor die Welt aktualisiert wird.

> Browser geben einen Controller erst frei, nachdem eine Taste darauf gedrückt wurde, während die Seite den Fokus hat.

```typescript
import { GamepadButton } from '@mavonengine/core/GamepadManager'

const pad = input.gamepads.primary // erster verbundener Controller, oder undefined

if (pad) {
  // Sticks nach der Deadzone, Y ist positiv, wenn nach oben gedrückt
  move.set(pad.leftStick.x, 0, -pad.leftStick.y)

  if (pad.justPressed(GamepadButton.South)) // A bei Xbox, Kreuz bei PlayStation
    jump()

  const throttle = pad.value(GamepadButton.RightTrigger) // 0 - 1
}

// Beliebiger verbundener Controller
input.gamepads.isPressed(GamepadButton.Start)
input.gamepads.justPressed(GamepadButton.A)
```

### Tasten

`GamepadButton` folgt dem W3C-Standard-Mapping. Verwende die layoutunabhängigen Namen (`South`, `East`, `West`, `North`, `LeftBumper`, `RightTrigger`, `DPadUp`, …) oder die Aliase für Xbox (`A`, `B`, `LB`, `RT`, `View`, `Menu`) und PlayStation (`Cross`, `Circle`, `L1`, `R2`, `Share`, `Options`).

### GamepadState

| Mitglied | Beschreibung |
|--------|-------------|
| `type` | `'xbox'`, `'playstation'`, `'nintendo'` oder `'generic'`, anhand der ID erkannt |
| `leftStick` / `rightStick` | `Vector2` nach der radialen Deadzone |
| `axes` | Rohe Achsen, wie vom Browser gemeldet |
| `isPressed(button)` | Taste wird gehalten |
| `justPressed(button)` / `justReleased(button)` | Taste hat sich seit dem vorherigen Update geändert |
| `value(button)` | Analogwert, 0 - 1 (Trigger) |
| `buttonLabel(button)` | Beschriftung für die Controller-Familie, z.B. `"Cross"` oder `"A"` |

### Einstellungen

```typescript
input.gamepads.stickDeadzone = 0.15   // Stick-Eingaben darunter werden ignoriert
input.gamepads.buttonThreshold = 0.5  // analoge Tasten gelten darüber als gedrückt
```

### Events

```typescript
input.gamepads.on('connected', (pad) => console.log(`${pad.type} connected`))
input.gamepads.on('disconnected', (pad) => {})
input.gamepads.on('buttondown', ({ gamepad, button }) => console.log(gamepad.buttonLabel(button)))
input.gamepads.on('buttonup', ({ gamepad, button }) => {})
```

### Vibration

```typescript
await input.gamepads.vibrate(pad.index, { duration: 200, strongMagnitude: 1, weakMagnitude: 0.5 })
// Löst zu false auf, wenn der Controller oder Browser es nicht unterstützt
```

Die Statusleiste des [Level-Editors](/de/kernkonzepte/level-editor) zeigt verbundene Controller mit einer Live-Debug-Ansicht.

## Opening the editor

The editor lives in `@mavonengine/editor` and is only loaded in development. Register it with `Game.devModeHook` before creating the game:

```typescript
import Game from '@mavonengine/core/Game'

if (import.meta.env.DEV) {
  Game.devModeHook = () => {
    import('@mavonengine/editor').then(({ default: Editor }) => Editor.registerListener())
  }
}
```

Then press `.` (or `Insert`) in the game. Projects made with `mavonengine create` are already set up.

## The running game stays

The editor keeps the scene that is loaded and the connection to the game server, so the other players and everything else the server sends keep showing while you edit.

- The client tells the server it opened the editor. The server removes its player, stops counting it as a player and sends it **every** entity in the world, not only those near a player.
- If the editor opens before the game joined a server, the multiplayer template connects as a spectator, without a player of its own.

## Layout

| Area | Built-in panels |
|------|-----------------|
| Left | **Scene** (the active scene's objects, live entities and unsaved changes), **Explorer** |
| Bottom | **Assets** (loaded models and textures; drag one into the scene) |
| Right | **Properties** of the selected object |

The status bar shows connected game controllers; click one to open the controller debug view with its live buttons and sticks.

## Saving scenes

`Ctrl+S` / `Cmd+S` saves the active [scene](/core-concepts/scenes) to `scenes/<name>.json` through the dev server. The game server watches the file, reloads it and every client gets the new map. Placing a plugin prefab also adds it to the plugin's `prefabs` in `mavonengine.json`, so its assets are shipped in the release.

## Custom panels

Dock your own tools next to the built-in panels. Give a React `component`, or a `mount` function to render with anything else:

```typescript
import Editor from '@mavonengine/editor'

Editor.registerPanel({
  id: 'my-tools',
  title: 'My tools',
  location: 'right', // 'left' | 'bottom' | 'right'
  mount(container, editor) {
    container.textContent = 'Hello from my panel'
    return () => { container.textContent = '' } // cleanup
  },
})
```

`registerPanel()` works before or after the editor boots and returns a function that removes the panel. Once booted, `editor.addPanel()` and `editor.removePanel(id)` do the same. Plugins get the editor in their `editor(ctx)` hook, see [Plugins](/tooling/plugins).

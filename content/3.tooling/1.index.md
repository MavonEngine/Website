MavonEngine ships with tools for the whole loop: scaffold a project, run it with a live dashboard, extend it with plugins, keep it up to date, ship only the assets you use, and let an AI assistant look at your running game.

::card-group
  :::card
  ---
  icon: i-lucide-square-terminal
  title: CLI
  to: /tooling/cli
  ---
  `mavonengine create`, `dev`, `plugins`, `install`, `make:plugin`, `build`, `doctor`, `upgrade`, `dashboard` and `mcp`.
  :::

  :::card
  ---
  icon: i-lucide-puzzle
  title: Plugins
  to: /tooling/plugins
  ---
  Engine plugins with client, server and asset parts, configured in `mavonengine.json`.
  :::

  :::card
  ---
  icon: i-lucide-layout-dashboard
  title: Admin Panel
  to: /tooling/admin-panel
  ---
  `/admin/` on the game server: runtime, scene graph, physics, routes and plugins, plus the pages plugins add.
  :::

  :::card
  ---
  icon: i-lucide-activity
  title: Monitoring
  to: /tooling/monitoring
  ---
  Tick time, CPU, bandwidth, players, logs, HTTP requests, packets and routes, in the terminal or the browser.
  :::

  :::card
  ---
  icon: i-lucide-bot
  title: AI Assistants
  to: /tooling/ai-assistants
  ---
  An MCP server that lets any AI assistant inspect the running game, use your plugins' tools and read these docs.
  :::

  :::card
  ---
  icon: i-lucide-message-square
  title: Chat
  to: /tooling/chat
  ---
  The `@mavonengine/chat` plugin: in-game text chat with rate limiting, mutes and proximity chat.
  :::

  :::card
  ---
  icon: i-lucide-database
  title: Database
  to: /tooling/database
  ---
  The `@mavonengine/sqlite` plugin: a database for the game server and its plugins, with migrations.
  :::

  :::card
  ---
  icon: i-lucide-key-round
  title: Player Accounts
  to: /tooling/auth
  ---
  The `@mavonengine/auth` plugin: accounts, logins, sessions, guests and mailed links, so the server knows who connects.
  :::

  :::card
  ---
  icon: i-lucide-list-checks
  title: Job Queue
  to: /tooling/queue
  ---
  `server.queue`: background jobs with retries, backoff, delays and failed jobs, in memory or in the database.
  :::

  :::card
  ---
  icon: i-lucide-mail
  title: Mail
  to: /tooling/mail
  ---
  The `@mavonengine/mail` plugin: queued mail in a layout you can change, over SMTP or any nodemailer transport.
  :::

  :::card
  ---
  icon: i-lucide-bell
  title: Notifications
  to: /tooling/notifications
  ---
  The `@mavonengine/notifications` plugin: `player.notify()` in the game, by mail and kept to read later.
  :::
::

MavonEngine ships with tools for the whole loop: scaffold a project, run it with a live dashboard, extend it with plugins, ship only the assets you use, and let an AI assistant look at your running game.

::card-group
  :::card
  ---
  icon: i-lucide-square-terminal
  title: CLI
  to: /tooling/cli
  ---
  `mavonengine create`, `dev`, `plugins`, `install`, `build`, `dashboard` and `mcp`.
  :::

  :::card
  ---
  icon: i-lucide-puzzle
  title: Plugins
  to: /tooling/plugins
  ---
  Engine plugins with client, server and asset parts, configured in `mavonengine.json`.
  :::

  :::card
  ---
  icon: i-lucide-activity
  title: Monitoring
  to: /tooling/monitoring
  ---
  Tick time, CPU, bandwidth, players, logs, HTTP requests, packets and routes, in the terminal or the browser.
  :::

  :::card
  ---
  icon: i-lucide-bot
  title: AI Assistants
  to: /tooling/ai-assistants
  ---
  An MCP server that lets any AI assistant inspect the running game and read these docs.
  :::

  :::card
  ---
  icon: i-lucide-message-square
  title: Chat
  to: /tooling/chat
  ---
  The `@mavonengine/chat` plugin: in-game text chat with rate limiting, mutes and proximity chat.
  :::
::

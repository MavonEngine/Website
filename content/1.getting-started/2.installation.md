Requires **Node 24** or newer.

## Scaffolding

Use the `create` command of the [MavonEngine CLI](/tooling/cli) to scaffold a new project.

### Multiplayer

```bash
npx @mavonengine/cli create my-game
```

This downloads the multiplayer template, installs its dependencies, starts the game server and opens the game in your browser, with a live [dashboard](/tooling/monitoring) of the server in the terminal.

The multiplayer template includes the authoritative server setup, networking boilerplate, and a working client/server split out of the box.

> `npx @mavonengine/create-bootstrap` still works and forwards to `mavonengine create`.

## Running the project

```bash
cd my-game
npm run dev
```

`npm run dev` runs `mavonengine dev`: it starts the game server and the client together and shows the dashboard. Everything runs on one port — the game server serves the client (with hot reload in dev) and the game socket next to its own API.

| URL | Description |
|-----|-------------|
| `http://localhost:8050/` | The game |
| `http://localhost:8050/#debug` | Debug mode: debug UI and physics colliders |
| `http://localhost:8050/api/game/health` | Server health endpoint |

Press `.` in the game to open the [level editor](/core-concepts/level-editor).

## Project layout

| Path | Description |
|------|-------------|
| `client/` | The browser game (`Game`), built with Vite |
| `server/` | The game server (`Server`); `server/src/Base/` holds the classes shared with the client |
| `scenes/` | [Scene](/core-concepts/scenes) files loaded by both sides |
| `mavonengine.json` | Enabled [plugins](/tooling/plugins) |
| `.mcp.json` | Registers the [MCP server](/tooling/ai-assistants) for AI assistants |
